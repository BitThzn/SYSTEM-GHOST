# SYSTEM://GHOST

## SOBRE MIM

Eu sou o **Ghost**.

Esse projeto é a forma que encontrei de transformar quem eu sou e o que estou construindo em algo visual, interativo e vivo.

O nome *Ghost* vem de um apelido antigo que meus amigos começaram a usar comigo há muito tempo. Ele nasceu na época em que eu jogava SQUAD e acabou ficando comigo até hoje. Com o tempo, isso deixou de ser só um nickname e virou parte da minha identidade.

---

## O QUE É ESSE PROJETO

Esse site é o meu portfólio pessoal, mas não no formato tradicional.

Eu quis criar algo que parecesse um **sistema vivo**, onde:

- Minha identidade é um “usuário do sistema”
- Meus projetos são módulos dentro desse sistema
- Meus objetivos aparecem como missões em execução
- Tudo isso é apresentado como um terminal interativo
